桌面版将 anyui-LIVE 带入本地的原生窗口。它具备网页版的全部能力，并额外提供对本机文件的直接访问与内置的模拟器构建。

与网页版一致的能力

桌面版运行的就是浏览器版同款编辑器，日常工作流完全不变：

  • 相同的工作区、编辑器、画布、预览、资源管理与历史记录。
  • 相同的智能体，用自然语言构建界面。
  • 相同的代码生成流水线，导出的工程完全一致。

桌面版的增强能力

桌面版可以直接操作你本机的文件，这是浏览器标签页做不到的：

  • 生成的代码直接写入工程目录。 通过原生目录选择器指定文件夹，生成的源码就地保存。首次授权后，后续导出静默更新该目录，无需再下载 ZIP 解压。
  • 一键创建可直接构建的模拟器工程。 应用会按目标版本（v8.3.7 或 v9.2.2）在你选定的目录中生成配套的 LVGL 模拟器模板。
  • 无需终端即可编译并运行模拟器。 直接在编辑器中构建、启动本地模拟器，查看实时构建日志，并可随时停止构建。Windows 上，构建工具链与 SDL2 库已随应用打包，可跳过模拟器指南中的手动环境配置。
  • 保留你的手工修改。 重新生成时，你在工程目录中手动编辑过的代码（如自定义事件逻辑）会被保留。
  • 保持目录同步。 重新生成会清理失效文件，已删除的屏幕、字体与图片真正从目录中消失，不会残留旧副本。
  • 原生文件保存。 二进制产物通过原生"另存为"对话框保存，工程包可以按真实目录结构导出与导入。
  • 安全关闭。 关闭应用前会提示未保存的改动，外部链接则在系统浏览器中打开。

系统要求

Windows（64 位）

  • Windows 10 或 Windows 11，x64 硬件。
  • ARM64 设备通过模拟运行 x64 安装包。
  • 安装包未签名。首次运行时 SmartScreen 会提示"Windows 已保护你的电脑"，选择更多信息 → 仍要运行。

macOS

  • macOS 12.0（Monterey）或更高版本。
  • Intel 机型原生运行。
  • Apple Silicon 机型通过 Rosetta 2 运行 Intel 版本，暂未提供原生 arm64 版本。
  • 构建未签名，Gatekeeper 会拦截首次启动。按住 Control 点击应用并选择打开以允许运行。
